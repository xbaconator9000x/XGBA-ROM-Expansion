# R43 XGBA Android tester — actual patched mGBA, not a stock-GBA preview

**Delivery goal:** an installable arm64 Android APK that embeds mGBA's original
CPU/LCD/Flash engine, extended with the *same* R7 guest-initiated resource
mailbox used in the verified R40–R42 native tests. The APK is generated by
[the R43 GitHub Action](../../.github/workflows/xgba-r43-android-emulator.yml),
not committed or signed with any private developer key.

## Install and use

1. Download the *successful* R43 CI artifact and extract it. Install
   `app-debug.apk` (Android may request permission to install downloaded APKs).
   The debug signing identity is ephemeral; it can differ between subsequent
   builds, so uninstalling an earlier preview APK may be necessary.
2. Tap **Load XGBA probe**. This demo is already bundled in the APK.
   You are now running a *real freestanding ARM7 GBA executable inside patched
   native mGBA*. Its tiny graphics/font and its three "world" resource strings
   are **entirely original demo material**, not copied Pokémon maps.
3. The display should read **XGBA REAL STORAGE** and **EXPANDED DATA OK!**.
   Use **R** and **L** to switch between the independently addressed
   `emerald.world`, `rocket.world` and `heart_soul.world` sources.
   Every switch triggers a new guest-initiated MMIO fetch. The counter above
   the controls should show **external reads increasing**.
4. Press **A** and look for the original homebrew guest's **EVENTS**
   counter to increase. This is the only intended probe-specific "mechanic";
   it does not claim any Pokémon event/battle compatibility.
5. Tap **Import game + sidecar ZIP** to import a *separately supplied XGBA-
   enabled executable + external pack*. The ZIP must contain exactly
   `game.gba`, `manifest.json` and `sidecar.bin` at top level.
   Use the producer/manifest format already supported by
   `tools/xgba_resource_sidecar.py`. The app verifies the complete GBA SHA
   against `source_identity.sha256`, every resource ID, bounds and digest,
   and leaves the files inside Android's private app directory.
6. The game's original SRAM/Flash save file is attached to the imported ROM
   identity and remains in the app's private storage between ordinary restarts.
   **Back up the original saves of any game you modify.** Do not import a
   stock Emerald/Team Rocket/Heart & Soul ROM and expect it to automatically
   execute the new extension; the *guest executable itself must contain XGBA
   fetch calls*, as in the original R40–R42 game builds.

**Why this is a real XGBA test:** the test asset offsets are **above
32 MiB**, the native guest CPU sends fetch requests to
`0x04FF8000`, and the emulator's built-in source provider validates
each requested resource's SHA before committing into the original GBA's
**256 KiB EWRAM**. A normal, unmodified emulator should display
`NEED PATCHED XGBA` from this same cartridge rather than claim success.

## Android implementation

- Java Activity, portrait 240×160 LCD, touch gamepad, no INTERNET permission
- Real native mGBA core with exact pinned sources
- Per-emulator XgbaGbaDevice instance and v1 source SHA binding
- Read-only host sidecar provider capped to 16 KiB per request
- Fail-closed resource hashes and no externally writable privileged paths
- mGBA's genuine Flash/SRAM persistence through its save-file API
- No game assets, original ROM or original saves inside source/APK artifact
- Android 8.0+ arm64, NDK 27, SDK 35, Gradle 8.9 and JDK 17
- Audio, polished launcher, patching stock ROMs and game/quest save namespace
  translation are **not** yet implemented; this is a TESTER, not a finished
  replacement for every existing emulator.

## Generate the opt-in probe locally

A release workflow uses `arm-none-eabi-gcc` to build the original
`probe/xgba_probe.c` and `probe/build_probe.py` to create the authored ROM,
manifest, sparse external sidecar and easy importable ZIP. For a **private**
variant, pass `--emerald`, `--rocket`, and `--heart-soul` file paths to the
Python builder; it reads your locally owned originals and displays
**per-source SHA fingerprints**, without copying their contents into the
bundle or uploading them to GitHub.

## Verifications

The R43 CI has separate gates for a real pinned native mGBA ARM7 probe (actual
GBA LCD capture and guest-side proof of an XGBA external fetch) and Android
arm64 Gradle/native compilation. Do not report install success until a person
or supported device instrumentation confirms it. Emulator/Android interactive
performance remains an open on-device acceptance test.

**R42 reminder:** the genuine original Emerald Bag, text, two adapted source-
labelled events and real Flash recovery have already been independently proven
in the native patched mGBA simulator. That successful CI is **not** the same
as having all three original game engines run together on Android.
