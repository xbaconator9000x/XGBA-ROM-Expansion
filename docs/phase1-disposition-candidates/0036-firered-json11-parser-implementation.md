## Whole-file function/class inventory
1. **License/includes and serialization:** includes `json11.h`, assertions, numeric/stdio headers; sets `max_depth=200`. `NullStruct` defines null equality/ordering. Overloaded internal `dump` serializes null, double (finite as `%.17g`, non-finite as `null`), int, bool, escaped strings (including U+2028/U+2029 sequences), arrays in vector order and objects in `std::map` key order. `Json::dump` delegates through the value pointer.
2. **Value representation:** `Value<tag,T>` implements typed tags, equality, ordering and dumping; specialized `JsonDouble`, `JsonInt`, `JsonBoolean`, `JsonString`, `JsonArray`, `JsonObject`, `JsonNull` implement typed overrides. `Statics`, `statics()`, `static_null()` provide shared null/booleans and default empty values. All `Json` constructors and typed/indexed accessors are defined. Wrong-type typed accessors return 0/false/empty values; absent object keys and out-of-bounds array indices return a static null `Json`, rather than throwing.
3. **Comparisons:** `Json::operator==` short-circuits pointer identity, compares tags then delegates; `operator<` orders unlike tags by enum value and like tags by underlying value. Numeric int/double wrappers compare via `number_value()`.
4. **Parser primitives:** `esc`, `in_range`, anonymous `JsonParser` state and `fail` preserve the first error. `consume_whitespace`, `consume_comment` and `consume_garbage` implement optional C-style comments; `get_next_token` detects exhaustion. `encode_utf8` and `parse_string` decode escapes and paired UTF-16 surrogate sequences. `parse_number` accepts JSON number syntax, returns `int` for certain short integer tokens and `double` otherwise. `expect` parses literal `true`, `false`, `null`.
5. **Recursive JSON parser:** `parse_json` rejects nesting deeper than 200 and handles literals, strings, numbers, object key/value pairs and arrays; object insertion is via `data[std::move(key)] = ...`, so a repeated key replaces the earlier value in the map. `Json::parse` checks trailing input after optional comments; `parse_multi` parses consecutive JSON values and tracks stop position/error. `has_shape` checks an object and each required field's exact JSON tag, setting a descriptive error on failure.
