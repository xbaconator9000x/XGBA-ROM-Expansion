- Introductory contract and bundled permissive license describe a C++11 JSON value/parser/serializer and require retaining the license notice in substantial copies. Numbers are described as double-represented for interoperability, with integer helper accessors; implementation may also use an integer-specialized value class. No promise of exact 64-bit integer round-trip is made.
- `#pragma once`; standard includes `string`, `vector`, `map`, `memory`, `initializer_list`; conditional MSVC <=1800 compatibility macros for `noexcept` and `snprintf`. - `namespace json11` defines `JsonParse {STANDARD, COMMENTS}`, forward `JsonValue`, and final value class `Json`. Its six tagged kinds are `NUL, NUMBER, BOOL, STRING, ARRAY, OBJECT`; arrays use `vector<Json>`, objects `map<string, Json>`. Constructors cover null, double/int, bool, string, C string, arrays/objects, custom `to_json()`, map-like and vector-like templates; `Json(void *) = delete` prevents accidental pointer-to-bool conversion.

The null `char*` overload reports `null input`.
- Six comparison operators are exposed (four derived from equality and less-than); `has_shape` checks object fields against an initializer-list of type pairs. A private shared `JsonValue` pointer delegates implementation. Abstract `JsonValue` declares virtual type/comparison/dump, typed defaults, indexed access and protected virtual destructor; `Json` and numeric value classes are friends.
