# R76 — original Emerald step-warp hook and recoverable failed source admission

R73 and R75 established source-authenticated original Rocket routes and two first-hop asset-closed destinations. However, R50 deliberately sets foreign-world warpCount=0, so no original Emerald step-warp signal had reached R73: it was solely a callable preflight. R76 inserts a real field_control_avatar.c TryStartWarpEventScript hook (original pinned pokeemerald source) that fires **only when native gameplay actually steps on a warp metatile** and the ordinary engine has no permitted warp. It compares original R49 deep-copied warp coordinates and original elevation with the real on-map position and uses R73 to validate the original destination via R49/R51 SHA-backed source pages. An R76 proof counts these physical observations and verified/refused source routes; no fake same-number Emerald warp is registered. Real R50 foreign event warpCount is deliberately still 0: physical per-map target activation and storage/Flash namespaces remain to implement before allowing player travel.

The previous R54 original Emerald case-0 failed foreign-asset preflight used an infinite for(;;) loop: a common expected missing-original-resource condition would therefore freeze the LCD. R76 makes ordinary invalid-source admissions return via a guarded native source0 Emerald 0:9 fallback. A busy source graphics DMA now retries case-0 on a later native frame, without racing the old graphics lease. The recovery clears pending Fly, does not record foreign arrival, resets ephemeral per-map art, and does not replace game maps with fabricated art. It resets the in-progress 3-leg demonstration (re-talk required). This safety path is not a full game-state preserving continue implementation: a later complete source-world Flash save contract remains necessary.

New ASan/UBSan C tile-hit/elevation tests, source patch contract tests and exact-head native Emerald ARM/mGBA regression tests cover code reachability and read-only safety. They do **not** represent completed playable foreign-door transitions or a three-world original-ROM playthrough. HnS raw-ROM permission/17 source-art gap and Rocket remaining 480-tile secondary tileset still block full acceptance. Keep PR draft.

## R77 — genuine source door and directional-arrow input coverage

The same actual Emerald A-button north-door and directional arrow-warp predicates now call the R76 original source route observer when the vanilla native warp event is missing (as required by R50 quarantine). This is required for the original Rocket three-way landing exits: not all original game warp triggers are simple step tiles. No route is falsely counted as completed: neither code path publishes a guessed Emerald destination; they only authenticate the source-original R49/R51 endpoints and preserve the original game's input/metatile eligibility. The native source build workflow now checks these anchored upstream source injections.

## R78: Original source warp event matching is independent of native Emerald metatile ID

R76–R77 initially gated the new probes on Emerald metatile behavior predicates, which may differ from original Rocket/Heart & Soul categories. The R78 change still requires a real physical original Emerald movement/door/arrow input path, but considers an original foreign R49 warp only when its exact original source coordinate and elevation match the actual player tile. The original in-engine predicates remain unchanged for native Emerald warps, and the foreign candidate continues to use R73 source-qualified target verification without committing a destination. The true Emerald door input is held north direction toward the facing tile, not necessarily A-button. These probes are evidence/candidate checks and cannot constitute a playable source-world warp or substitute for original graphics or script admission.
