# R75 — Original Rocket one-hop asset expansion (PRIVATE assets only)

The actual owner-private original Rocket ROM SHA-256 was verified against the repository source pin. A private extension preserved all 377 R64 resource entries exactly and added **51 original-source entries**, yielding **428/428 SHA-verified resources**. New resources cover 7 original sprite graphics IDs (5, 26, 46, 59, 100, 105, 215) and 3 source tileset descriptors (0xe9ff80, 0xe9fdd0, 0xea02e8). Rocket landing exits to source-group 35 maps 2 and 4 have first-viewport original source art present in the private extension. Map 35:0 remains quarantined: the original 0xea0300 descriptor decompresses to **15,360 bytes (480 tiles)** while the verified version-2 secondary capacity is **12,288 bytes (384 tiles)**. No clipping, fabricated image or silent override.

Public source tool R75 reuses the established R53 and R60 original ROM-authenticated extractors, R68 host SHA provider validation and R52 map-specific descriptor CRC. Exact original/private resources stay outside public GitHub; only extraction code, tests and aggregate facts live here. This is original source asset compilation, **not a successful native Emerald source-world transition**. R73 and R74 bring safe source-specific route admission and EWRAM MMIO names, but player-door hook, native target-map graphics admission, foreign script execution and cold-save continuity remain unproven. Heart & Soul full original ROM raw bytes are still inaccessible in this runtime; Johto first-landing art remains missing. Keep PR draft.
