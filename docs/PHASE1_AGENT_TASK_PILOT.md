# Phase 1 Porymap Copilot pilot — retired

**Status: RETIRED on 12 November 2026.**

The earlier pilot was a limited experiment in handing off a single source-backed Porymap semantic-review task to GitHub Copilot, with strict branch/source pins, no automatic semantic approval and an explicit stop condition. It was not a prerequisite for the verified XGBA external-resource integration.

The pilot's workflow, dispatcher and task-specific test harness have been deleted from the current tree. It is no longer possible to invoke the pilot's previous manual-dispatch mode from current `main`. Historical execution data remains in old Git revisions and GitHub Actions records; this removal is **not a Git-history rewrite**.

For current source-backed integration, see the [XGBA project overview](../README.md), [architecture](xgba-integration-architecture.md), and verified native regression evidence.
